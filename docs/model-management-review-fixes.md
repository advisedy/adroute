# 模型管理独立审查修复（0.7.1）

## 范围

保留 0.7.0 的组／模型结构和原生前端，修复独立审查指出的缺陷，不新增迁移、订阅、协议转换、共享凭据池或测速统计系统。配置仍为 version 5。

## 修复清单

- OpenCode 同步复用 `ParsePublicModelID`，支持合法的点、下划线、大写名称，不再套旧 slug 正则。
- 测速校验 JSON 终态和 SSE 事件／状态一致性；failed/error 立即失败，不能被后续成功覆盖。
- 文本测速及工具结构测试收到有效终态立即关闭响应体，计时到有效结束而非 EOF，避免成功误超时和速度失真。
- 超出 192-token 请求预算的用量不计算可信速度；未知 incomplete reason 不回显，提前结束不一概写成达到输出上限。
- 模型保存、默认选择、组操作、删除及目录重试使用持续 pending 状态，刷新／重绘不会解除单飞，提交入口也防止重入。
- 内联建组响应只更新其原草稿；全局组状态可更新，但不能切换新草稿的组。模型／组／删除回调和错误绑定界面实例。
- 测速结果的私有内存身份覆盖 URL、真实 ID、Key 与其他目标配置；换 Key 后刷新不保留旧成功结果，旧请求错误也不挂到新目标上。
- 工具结构测试的成功与错误核对目标版本和连接身份；切换目标不显示旧模型的验证证据。
- 诊断采集／交接核对私有上游快照；改模型、地址或 Key 后，旧样本不自动附到当前目标 Prompt，不需要重建条目或公开 ID。
- 严格区分管理接口 missing/null/字符串。清默认需显式 modelId=null 或空字符串；解除修复需显式 profile=none；apiKey:null 拒绝，省略或空串仍按约定保留。
- 模型名称与组名按原始输入校验，非法空白不裁剪保存。后端冲突错误保留 code 并定位到表单字段。
- 目录发布失败通过管理状态与页面警告报告，提供受认证的空体 `POST /api/catalog/retry`。只重试文件发布，不重复保存模型或增加配置 revision。
- 同 revision 的旧状态读取不能恢复刚被重试清除的发布警告；目录发布与配置保存仍不虚称跨文件原子。
- 补齐 quickTest 能力保护和退出后的隐藏目标／请求元数据清理；浏览器 fixture 隔离 HOME/XDG_CONFIG_HOME。

## 实现取舍

- 沿用用户明确选择的当前目录修改，不为尚无提交的仓库建立基线提交；采用外部只读基线与差异文件留痕。代价是变更比较不依赖 Git 提交范围。
- 晚到写响应可以反映全局已提交状态，但不能修改新草稿字段或错误区。代价是用户关闭表单后，服务器已完成的保存仍会正常出现，而不是假装取消。
- 上游报告超过本次固定输出预算的用量不作为可信速率；文本仍可判为有返回。代价是不合规上游的该次 token/s 不显示，而不是伪造更精确的 tokenizer 结果。
- 发布重试不增加模型配置 revision；前端以状态应用代次防止旧的同 revision 读取恢复已清除的警告，仍接收真正更新的配置 revision。代价是失效的旧读取会被丢弃，由后续刷新取得最新状态，不重复提交模型。
